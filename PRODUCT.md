# Product

## Register

product

## Users

Shop administrators and staff managing a multi-tenant shop-management backend (go-echo-template): users, shops, roles/permissions, menus, products, and orders. Used at a desk or counter, often alongside other back-office tasks, all copy in Lao.

## Product Purpose

Live Commerce is the Nuxt3 + Vuetify admin frontend for the go-echo-template shop-management API. It provides CRUD screens (list, create, edit, detail) for backend entities — currently Login, Users, Shop, ShopSetting, ShopBankAccount, Role, Permission, MainMenu, SubMenu — so shop staff can configure and operate their shop without touching the API directly.

## Brand Personality

Modern, clean, trustworthy (ທັນສະໄໝ, ສະອາດ, ໜ້າເຊື່ອຖື). Reads easily at a glance, no unnecessary decoration, inspires confidence for people managing real money and shop data.

## Anti-references

Not a marketing/landing page. Avoid SaaS-dashboard clichés (gradient hero metrics, glassmorphism cards, numbered eyebrows on every section). Avoid dense, cramped enterprise-software tables that force horizontal scrolling on mobile with no adaptation.

## Design Principles

- Data tables are the primary surface — legibility and scanability beat decoration.
- Every list/CRUD screen follows the same shape (list → create → edit → detail) so staff learn the pattern once.
- Mobile and small-screen use is real (counter/POS context), not an afterthought.
- Lao-language labels throughout; typography must support Lao script clearly at table-row density.
- Trust through restraint: clear status indicators (chips), confirmations before destructive actions, no dark patterns.

## Accessibility & Inclusion

Standard WCAG AA contrast for body text and table content. No specific assistive-tech requirements stated; keep tap targets usable on mobile-width viewports since staff may use tablets/phones at the counter.
